# DEC-039: Adopt the Hyperion null-double-at-CONTRACT and node-test runner changes
Date: 2026-09-23
Status: accepted
Tier: baseline

## Context
The Hyperion framework under `hyperion/` changed, and `init_project.py --upgrade` rendered the
change into `CLAUDE.md`, `.claude/` and `.hyperion/`. The upgrade moves who writes the null
double, changes the G3 criterion, makes the test runner a project declaration, and moves the
hazard-to-requirement link. Pivot runs under whatever is committed, so leaving the change
uncommitted leaves the scope hook, the skills and the checkers disagreeing with the tree.
jay-pryor decided to adopt it, relayed by a QUERY session.

## Decision
Pivot adopts the upgrade. (1) The CONTRACT session writes `modules/*/null_double.*`, and
CONFORMANCE and IMPLEMENT must not. (2) G3 is passed when every module has a null double
and its suite fails against it. (3) Pivot declares the node-test runner in `.hyperion/runner`,
and `check_traces.py` and `check_null_doubles.py` read tests through
`hyperion/tooling/runners.py`. (4) Conformance files are named
`test_<kind>[.<part>].test.js`, done in 7e3971a. (5) Hazards no longer carry `requirement:`;
the link is each requirement's `source:`. Pivot's 12 hazards still carry the old field, and
removing it is GATE work, not part of this change.

## Alternatives considered
### Keep the earlier framework version
Rejected because: the checkers could not read Pivot's JavaScript results, so the null-double
check and the trace check could not run against the node suites at all.

### Let the CONFORMANCE session write the null double
Rejected because: a session writing both the suite and what it must fail against can tune
both until the check is green (CORE-TST-002).

## Consequences
- Makes easy: `check_null_doubles.py` and `check_traces.py` run on Pivot's node suites.
- Makes hard: a module without a null double blocks G3; it needs a CONTRACT session.
- Locks in: the `test_<kind>[.<part>].test.js` naming and the `source:` direction of the hazard link.

## Reversal
Cost to undo: hours. Re-render from the earlier framework version and revert the commit.
Would be triggered by: a runner Pivot moves to that `runners.py` does not describe.
